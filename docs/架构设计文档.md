## 1. 产品概述

### 1.1 定位
从「PDF 文本提取工具」升级为 **企业级文档智能识别（Document AI）服务**：输入任意 PDF/图片/扫描件，输出**高精度的结构化数据**（文本、表格、版式、字段、实体），以标准 API 交付。

### 1.2 核心价值
- **识别精度**：复杂版式（图文混排、PPT、扫描件、表格）的高精度结构化提取
- **商业可用**：SLA、多租户、计费、高可用、安全合规
- **可演进**：模块化管线，持续迭代模型与算法

### 1.3 目标用户场景
| 场景 | 输入 | 输出 |
|------|------|------|
| 表格提取 | PDF/Excel/图片中的表格 | 结构化表格（JSON/CSV/Excel） |
| 合同/票据解析 | 扫描件/PDF | 关键字段（金额/日期/条款） |
| 文档入库 | 各类PDF | 干净的 Markdown/文本 + 版式 |
| 知识库构建 | 混合文档 | 结构化语料 |

## 3. 总体架构（分层）

```
┌────────────────────────────────────────────────────────────┐
│  客户端层:  Web控制台 / SDK(Java/Python/Node) / REST/CLI      │
├────────────────────────────────────────────────────────────┤
│  API 网关层:  鉴权(JWT/Key) · 限流 · 计费计量 · 路由 · WAF    │
├────────────────────────────────────────────────────────────┤
│  任务编排层:  任务队列(Celery/Redis) · 分片 · 幂等 · 重试      │
│             进度查询 · 异步回调(Webhook) · 配额管理           │
├────────────────────────────────────────────────────────────┤
│  识别引擎层 (核心, 可水平扩展, 见 §4)                        │
│    ┌────────────────────────────────────────────┐          │
│    │  管线: 解析→渲染→版式→OCR→结构化→后处理       │          │
│    │  子引擎: 文本OCR / 表格定位 / 表格结构 /      │          │
│    │         表格内容 / 公式 / 字段抽取(多模型)    │          │
│    └────────────────────────────────────────────┘          │
├────────────────────────────────────────────────────────────┤
│  存储层:  PG(任务/元数据) · Redis(队列/缓存) · 对象存储(S3/OSS) │
│          向量库(检索) · 结果缓存                              │
├────────────────────────────────────────────────────────────┤
│  可观测层:  日志(ELK) · 指标(Prometheus/Grafana) · 链路(Tempo) │
│           告警 · 成本核算 · 模型质量看板                       │
└────────────────────────────────────────────────────────────┘
```

**关键设计原则**
- **无状态识别引擎**：引擎Worker无状态，通过消息队列水平扩展，支撑高并发
- **管线可插拔**：每个识别环节独立成组件，可替换/升级/灰度
- **任务异步化**：长任务走队列 + 回调，同步/异步双模式
- **模型与代码解耦**：模型版本化管理，支持多模型并行与灰度

## 4. 识别引擎详细设计

### 4.1 识别管线（Pipeline）

```
输入文档
  │
  ├─ 1. 文档解析      PyMuPDF/pdfplumber  → 页对象、文本层、嵌入对象
  ├─ 2. 页面渲染      PyMuPDF/poppler → 高清图像（多 DPI，按需）
  ├─ 3. 版式分析      版面分割（文本块/图片/表格/标题区域）
  ├─ 4. 分区识别      按版式类型分流到对应子引擎
  │     ├─ 文本区 → OCR（Marker/surya, PaddleOCR, Tesseract）
  │     ├─ 表格区 → 表格管线（§4.2）
  │     └─ 公式/图形 → 专项模型
  ├─ 5. 结构化组装    JSON Schema 输出 + 坐标 + 置信度
  └─ 6. 后处理        纠错、去重、字段映射、版本化
```

### 4.2 表格提取管线（核心商业能力）★

> 依据课件《商业项目落地场景——表格信息提取方式》，表格提取分两大步：
> **第1步 表格定位**（本节） → **第2步 表格结构识别与内容提取**（V2 扩展）

**第1步：表格定位** —— 精确获取表格边界坐标 `(x0,y0,x1,y1)`

```
a. 初步识别（文本/向量层）
   ├─ PyMuPDF: 检测表格线(TableFinder) / 文本块对齐
   └─ pdfplumber: find_tables() 基于线&文本对齐的候选区域
        ↓ 定位不准 或 图片/扫描件
b. 图像化转换
   └─ 页面渲染为高清图像（300 DPI+）
c. OpenCV 视觉处理
   ├─ 线条检测: 霍夫变换(Hough) 强化/重建表格边框线
   ├─ 轮廓检测: findContours 找最大矩形候选区（线框/密集文本）
   └─ 网格切分: 横线×竖线交叉 → 单元格网格（九宫格示意）
d. 坐标融合
   └─ 结合文本坐标(逻辑) + 图像分析(视觉) → 加权融合
       输出最终表格边界坐标列表 [(x0,y0,x1,y1), ...]
```

**第2步：表格结构识别与内容提取**（V2 路线）
```
- 结构识别: 行列线聚类、合并单元格检测(跨行/跨列)、表头识别
- 单元格内容: 对每个 cell 区域局部 OCR（高精度）
- 结构化输出: {table_id, rows:[[cell,coord,conf]], header:[...]}
- 导出: JSON / CSV / Excel / 转 Markdown 表格
```

### 4.3 引擎技术选型（演进式）

| 环节 | V1（当前） | V2 演进 | 备注 |
|------|-----------|---------|------|
| 文档解析 | PyMuPDF | PyMuPDF + pdfplumber | 双引擎交叉验证 |
| Office/ODF/EPUB 解析 | ✅ **anydoc**（Rust，毫秒级，统一 GFM） | anydoc + 内置解析回退 | 老格式原生解析 |
| 表格定位 | — | PyMuPDF + OpenCV | 文本+视觉融合 |
| 表格结构 | — | 深度模型 (Table Transformer / SLANet) | 复杂表格 |
| 文本 OCR | Marker(surya) | PaddleOCR(中文强) + Marker 并存 | 按语种路由 |
| 服务框架 | Flask | FastAPI + Celery | 异步/高并发 |
| 部署 | 单机 | Docker + K8s | 水平扩展 |

> **V1 已知技术债**：Marker 2.0 + llama-server 在 Windows CPU 上推理超时不稳，
> 商业版应切换为 **PaddleOCR（服务化，CPU/GPU 均可）** 或 Marker 的稳定服务化部署。

## 5. 商业化能力设计

### 5.1 API 管理
- REST API + 各语言 SDK（Java/Python/Node）
- 密钥鉴权（AK/SK），JWT 短期令牌
- 同步（小文件）与异步（大文件 + Webhook 回调）双模式
- API 版本化 `/v1/`，向后兼容

### 5.2 计费与配额
- 计量维度：页数 / 文档数 / 表格数 / 识别类型
- 计费模式：按量（每千页）、包月、企业年费
- 配额管理：租户级 QPS、并发、存储上限

### 5.3 SLA 与高可用
- 可用性目标：99.9%（多可用区、无状态Worker + 队列容错）
- 吞吐：水平扩展（无状态 + 消息队列）
- 延迟：同步 API P95 < 5s（小文件）；异步任务保障
- 幂等与重试：任务ID去重、失败重投、死信队列

### 5.4 多租户与安全
- 租户隔离：数据、配额、密钥、审计日志
- 传输/存储加密（TLS / AES-256）
- 敏感信息脱敏、文档水印溯源
- 合规：数据不留存开关、GDPR/等保参考

## 7. 质量评估与可观测

### 7.1 评估体系
- **文本**：字符错误率 CER、词错误率 WER
- **表格**：表格级F1（行列匹配）、单元格内容准确率
- **版式**：区域分类准确率、结构完整性
- **场景**：字段抽取精确率/召回率（票据/合同基准集）

### 7.2 监控指标
- 业务：QPS、任务成功率、吞吐、页/天
- 性能：P50/P95/P99 延迟、队列积压
- 质量：识别置信度分布、模型漂移检测
- 成本：单页成本、引擎资源占用

### 7.3 数据闭环
标注平台 → 难例回流 → 微调/规则迭代 → 灰度 → 评估对比
